检查日期 2026-10-25。范围：修改源码、合成测试、既有正式站只读探测。不是对 NAS、Cloudflare 和第三方模型的完整渗透测试。

## 已验证

- 公开 Fork 无新增真实秘密或训练数据；测试数据、备份、虚拟环境及本机截图被忽略。提交内容经过秘密模式扫描。未提取浏览器 Cookie/Token，也未使用真实 DeepSeek Key。
- 独立 Node 栈 Web/API 均为 127.0.0.1；Docker 只发布回环 8081，API 无主机端口；独立目录、网络、镜像、项目、RP/Origin。
- 真实 API 合成测试验证未登录 401、两个客户端相同 baseRev 写入产生 409、组级冲突合并及重启持久化。
- 虚拟 Passkey 创建/重新登录并恢复训练已通过；这不是 iPhone Face ID 实机测试。
- AI payload 使用显式白名单，不复制器材备注/私有字段；测试输入含提示注入文本，不能进入规则上下文。原 Provider 隔离和上游权限测试继续执行。个人模块未添加 shell/文件系统工具。
- AI 确认后处方修改有独立白名单及最终次数范围校验；不可改变循环/历史；未确认项不应用，活动会话保留快照。
- 完整备份路径/散列/清单/认证 secret 校验及恢复后登录通过；测试不接触正式目录。
- 升级运行依赖 undici 至 7.30.1+，修复原有高危 content-encoding 拒绝服务问题。依据：[维护方公告 GHSA-xjj6-f33q-929c](https://github.com/advisories/GHSA-xjj6-f33q-929c)。前端/API 运行依赖当前 npm audit 为 0 已知漏洞；不等于全部镜像/系统无漏洞。
- 正式 HTTPS 返回 200，证书验证成功；NAS 8080 健康接口 ok/writable true（只读，不代表所有配置审计通过）。

## 运行边界

训练数据导入的自由文本不构成模型权限。AI 输出仍按原契约验证，且最终写入经过个人策略白名单。规则引擎不接受模型指定的“已完成/已休息”事实。用户若自行修改整个浏览器状态，本应用仍是原有用户自管理数据模型，不提供防本人篡改证明。

公开测试须保护全主机并禁止旁路；NAS 管理页面、Docker socket 和源数据目录不得通过 Tunnel 发布。正式服务未被修改、停止或替换，正式发布/回滚脚本未执行。
